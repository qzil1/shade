# Shade 1.1.2 验收记录

日期：2026-09-25。环境：macOS 26.5.2，Apple Silicon，Swift 6.3.3。

## 已完成的可重复检查

- 核心测试覆盖 25 个行为：窗口 PID/几何初次匹配、重叠同尺寸窗口、无效尺寸、持续窗口身份、窗口消失、跨屏窄边、负坐标屏幕、三种显示策略、逐屏排除、偏好恢复、数值边界和独立深色配置。
- 原生测试在 `NSApplication.run()` 事件循环中执行，检查非 key 窗口、鼠标穿透、无额外阴影、渲染图层、实际窗口列表、兼容遮罩的活动区域透明、附加屏幕覆盖、过期淡出取消和立即移除。
- 当前锁屏会话中的跨应用相对排序不能稳定复现。此前一次成功不作为该路径验收依据。实现已增加实际 z-order 检查和矩形兼容路径，当前测试报告实际走兼容路径。
- 菜单面板和设置页浅色／深色离屏渲染，检查布局；离屏缓存叠加实色背景以便检查，不代表 macOS 玻璃材质的真实桌面外观。
- 优化的 arm64 和 x86_64 Universal 2 构建、Info.plist 校验、代码签名校验。
- 独立代码审查：修正了拖动时 AX/CG 坐标竞态、Fn 状态恢复、菜单面板聚焦时丢失目标，以及显示器设置与快捷键不同步的问题。

## 1.1.2 窗口移动修复

- 修复窗口几何变化错误触发排序重建的问题：原生排序已经验证、目标和层级未变时，移动/缩放继续使用系统遮挡，不切换成跟随坐标的矩形挖孔。
- 修复连续几何更新反复取消 40ms 排序检查的问题：同一目标的待完成检查保留原截止时间，同时更新安全透明区域。等待验证的状态不会被误认为“已确认兼容模式”。没有增加常驻高频轮询，也没有给透明区域加追赶动画。
- 两项关键回归分别在修复前失败：首次移动丢失原生模式、连续移动阻止初次排序检查完成。最终 `./test.sh --integration` 通过 25 项核心检查及 34 项原生检查，覆盖密集移动、亮度稳定、受控真实窗口连续位置变化和此前总览暂停/恢复。
- 验证边界：原生测试证明实际 WindowServer 排序与图层状态；用户窗口的自动拖动操作未观测到坐标变化，不计为手感验收。实际触控板拖动、兼容模式的边缘观感仍需用户体验确认。

## 1.1.1 总览手势修复

- 在解锁的 macOS 26.5.2 桌面上，实测进入 Mission Control 后，遮罩的 WindowServer 边界由 1470×956 变成屏幕中心的 1×1，普通窗口同时变为缩略图坐标。原来的刷新仍会使用这些坐标更新透明区域，并重复置顶兼容遮罩。
- `OverlayWindow` 现在检查自身的实际显示边界；系统变换期间立即清空调暗内容、取消延迟排序、保留系统管理的 transient 窗口，忽略缩略图坐标。边界恢复后重新建立安全透明区域。兼容模式更新透明区域不再反复置顶。
- `./test.sh --integration` 通过 25 项核心检查和 22 项原生检查。其中新增 5 项覆盖总览暂停、拒绝缩略图坐标、延迟回调、正常恢复和回调期间开始总览。新增暂停测试在修复前实际失败，修复后通过。
- 用生产 `OverlayWindow` 的独立实时测试进程配合真正的 Mission Control 切换，记录到整个总览及退出动画期间图层 opacity 为 0，正常坐标恢复后 opacity 回到测试值 0.01。此证据是系统窗口元数据与真实图层状态，未录屏，也不等于触控板每一帧的视觉验收。
- Universal 2 构建及严格签名验证通过。已更新 `/Applications/Shade.app`；更新前备份在 `Shade/.build/Shade-before-1.1.1.zip`。本地 ad-hoc 签名改变导致系统要求重新授予辅助功能权限。
- 三指下滑 App Exposé、连续反向滑动、半途取消手势以及多屏总览仍需真实触控板验收；不能把 `.transient` 标记检查当作这些场景的验收。
